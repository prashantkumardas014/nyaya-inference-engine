## Overview

This project is an educational demonstration that maps selected concepts from **Nyaya** (one of the six orthodox schools of Indian philosophy) onto components of a classical rule-based expert system. It implements a small **forward-chaining inference engine** in Python that derives new facts from initial facts using IF-THEN rules.

The project illustrates how Nyaya's *anumāna* (inference) and the five-membered *Pañcāvayava Vākya* correspond loosely to the components of a rule-based system, without claiming that the two are identical.
